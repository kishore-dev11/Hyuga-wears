# Hyuga-wears
# 🌐 Modern Animated Website using JavaScript & Tailwind CSS

A fully responsive and visually appealing modern website built using **JavaScript** and **Tailwind CSS**, designed with a focus on smooth **animations**, elegant **transitions**, and clean UI/UX principles.

This project demonstrates how lightweight tools like Tailwind CSS and Vanilla JavaScript can be used to create interactive and engaging web interfaces without relying on heavy frameworks.

---

## 📖 About the Project

This website is created to showcase modern frontend development techniques such as:

- Utility-first styling using Tailwind CSS  
- DOM manipulation using Vanilla JavaScript  
- Smooth scrolling effects  
- Interactive UI components  
- Animation and transition effects for better user experience  

The goal of this project is to build a fast, minimal, and aesthetically pleasing website that works seamlessly across all devices.

---

## ✨ Key Features

- 🎯 Fully responsive design (Mobile, Tablet, Desktop)
- ⚡ High performance with minimal dependencies
- 🎨 Clean and modern UI using Tailwind CSS
- ✨ Smooth animations and hover effects
- 🔄 Transition effects for interactive elements
- 📱 Mobile-first approach
- 🧩 Easy to customize and extend
